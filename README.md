# Paper Trail Books Marketing Copy Generator

A Flask web application that generates marketing copy for books, lets users review the results, and saves approved copies in an SQLite database.

## Features

- Generate marketing copy for tweets, emails, and flyers.
- Use book details and brand voice to guide copy generation.
- Review the generated copy using a checklist.
- Save approved marketing copy to SQLite.
- View saved entries on the `/history` page.
- Responsive Bootstrap interface.
- Automated tests with pytest.

## Requirements

- Python 3.11 or compatible version
- pip
- Git
